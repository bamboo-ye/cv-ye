03 / PARALLELISM & RECOVERY 并行提速，失败只重试未完成部分 以 Go 多 Run 调度、持久 Python 进程池和 LangGraph 构建三层有界并行，执行前预留调用与成本预算。通过 Checkpoint、租约、Revision Fencing 和 Outbox / Inbox 恢复长任务；内容寻址缓存复用成功分片，仅补失败或缺失批次，并结算已发生用量。
04 / RAG & MEMORY 回答有来源，长期记忆可管理 融合近期会话、结构化摘要、长期记忆和 Wiki 证据，按节点控制上下文预算。Qdrant 稠密 / 稀疏检索结合 RRF 与可配置重排，提供引用和证据不足提示；支持记忆纠正、有效期管理，以及文档变更或撤销共享后的检索与缓存失效。
05 / MULTIMODAL DELIVERY PDF / PPT 生成与质量校验一体化 实现 PDF 版面翻译及 PPT 叙事、表格和视觉生成，优先复用主题匹配的来源页原图，按需补充生成图片。围绕来源覆盖、字段证据、语言一致性、内容容量和布局检查交付物，以有界修复和模型回退处理结构化输出错误。
06 / GOVERNANCE & OBSERVABILITY Agent 可调试、可发布、可观测 通过 Agent Studio 调试节点，将 Agent、Prompt 和模型配置版本化，Run 固定快照，支持评测、稳定分流及灰度停流回滚。接入 OpenTelemetry、Prometheus、Loki 和可选 Langfuse，关联耗时、用量、成本与错误，并提供权限、额度和审计能力。
